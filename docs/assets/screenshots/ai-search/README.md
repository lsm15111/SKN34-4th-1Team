# AI 대화 검색 실제 사용 화면

메인 README의 **8.1 AI 대화 검색**에서 사용하는 실제 웹 화면 GIF입니다. 관리자에게 보이는 **Gov 에이전트** 화면에서 검색 흐름을 진행했습니다.

- 캡처일: 2026-10-14
- 화면: 로컬 React 웹 `http://127.0.0.1:5173/app/chat`, `main` `0edcd570` 기준 화면에 스크롤바 자리를 미리 두는 변경(`scrollbar-gutter: stable`)을 적용한 상태입니다. 계정 정보가 나오지 않도록 사이드바를 접었습니다.
- 계정: 로컬 개발용 관리자 계정. 검색 조건의 소재지·업종·설립연도는 이 계정에 등록된 가상 기업 정보와 질문에서 왔습니다.
- 질문: `서울에 있는 AI 창업기업입니다. 사업화 지원사업을 찾아주세요.`
- 실행: 새 검색 화면에서 질문 입력 → 전송 → 조건 제안 카드의 `검색 조건 자세히` 펼침 → `이 조건으로 검색` → 추천 결과 확인 → 첫 번째 추천 공고의 `원문 근거 1건` 펼침 → `이 공고로 작업`을 한 번의 실행으로 순서대로 진행했습니다.
- AI: 현재 저장소의 AI 코드를 실행해 Gov 에이전트 경로 선택은 `gpt-5-nano`, 조건 해석은 `gpt-5.6-luna`, 추천 평가는 `gpt-5.6-sol`(priority)로 새로 생성하고, 질문 임베딩(`text-embedding-3-small`)과 기존 Elasticsearch·Qdrant 색인으로 후보를 검색했습니다. Core 사용량 기록 기준 경로 선택 입력 2,568·출력 259토큰, 조건 해석 입력 3,220·출력 100토큰, 추천 평가 입력 35,885·출력 3,652토큰으로 단가표 기준 약 0.43달러입니다.
- 결과: 확인 필요 공고 2건을 반환했습니다. 결과 화면은 첫 번째 공고를 보여 줍니다. 공고 상태·마감일·관련도는 캡처 당시 화면의 표시값이며, 최신 공고 수집이나 추천 품질 전체를 검증한 기록은 아닙니다.
- 편집: 데스크톱 화면(폭 760px 이상)의 800×882 보기를 브라우저 창에 맞춰 0.894배로 표시한 화면을 캡처하고, 화면 영역만 잘라 **715×788**(기존 800×882 사진과 같은 비율) GIF로 묶었습니다. 프레임은 실제 조작 사이에 찍은 정지 화면이며, 단계마다 3~6장을 0.35~2.8초씩 보여 줍니다. 디더링 없이 256색으로 줄였고, 응답 대체·화면 문구 수정·이미지 합성은 하지 않았습니다.
